---
title: Error codes
description: Stable public error codes and HTTP statuses from the protocol.
icon: CircleX
---

Registered operations return `{ error: { code, message } }`. `code` is one of the values below. The status is `publicErrorStatuses` in `@linealabs/protocol`.

| Code                                  | Status |
| ------------------------------------- | ------ |
| `validation_failed`                   | 400    |
| `authentication_failed`               | 401    |
| `identity_exchange_failed`            | 401    |
| `session_expired`                     | 401    |
| `session_revoked`                     | 401    |
| `proof_invalid`                       | 401    |
| `scope_denied`                        | 403    |
| `connection_scope_insufficient`       | 403    |
| `workflow_start_not_allowed`          | 403    |
| `resource_not_found`                  | 404    |
| `workflow_binding_not_found`          | 404    |
| `approval_request_wrong_subject`      | 404    |
| `external_subject_disabled`           | 409    |
| `approval_request_expired`            | 409    |
| `approval_request_already_decided`    | 409    |
| `approval_request_cancelled`          | 409    |
| `decision_conflict`                   | 409    |
| `idempotency_conflict`                | 409    |
| `conversation_identity_conflict`      | 409    |
| `connection_reauthorization_required` | 409    |
| `execution_not_cancellable`           | 409    |
| `workflow_binding_disabled`           | 409    |
| `workflow_binding_incompatible`       | 409    |
| `action_intent_stale`                 | 409    |
| `event_cursor_expired`                | 410    |
| `rate_limited`                        | 429    |
| `identity_provider_unavailable`       | 503    |
| `service_unavailable`                 | 503    |

Each operation lists the codes it can return. The route reference is that list. A code in this table is not promised on every route.
