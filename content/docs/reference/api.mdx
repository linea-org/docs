This page lists the 50 operations in `operationRegistry` at commit `d8ce4e5`. Shapes, rate limits, and idempotency notes are in the generated [route reference](https://github.com/linea-org/linea/blob/d8ce4e5ac7d53de54e01b511e48d3b7dda401eca/docs/route-reference.md). Do not treat a path as a compatibility contract unless it appears there.

SDK methods for these operations are on the [SDK](/docs/reference/sdk) page. Paths that only the workspace `Linea` client calls, and that are missing here, are not registry operations.

## Environment key

| Operation                             | Method and path                                                       | Status | Scope                 |
| ------------------------------------- | --------------------------------------------------------------------- | ------ | --------------------- |
| `provisionEnvironmentSubject`         | `POST /v1/environments/{environmentId}/subjects`                      | 200    | `subjects:provision`  |
| `createEnvironmentConversation`       | `POST /v1/environments/{environmentId}/conversations`                 | 201    | `conversations:write` |
| `listEnvironmentConversations`        | `GET /v1/environments/{environmentId}/conversations`                  | 200    | `conversations:read`  |
| `getEnvironmentConversation`          | `GET /v1/environments/{environmentId}/conversations/{conversationId}` | 200    | `conversations:read`  |
| `startEnvironmentExecution`           | `POST /v1/environments/{environmentId}/executions`                    | 202    | `executions:start`    |
| `getEnvironmentExecution`             | `GET /v1/executions/{executionId}`                                    | 200    | `executions:read`     |
| `cancelEnvironmentExecution`          | `POST /v1/executions/{executionId}/cancel`                            | 200    | `executions:cancel`   |
| `listEnvironmentConnectorAuditEvents` | `GET /v1/environments/{environmentId}/audit-events`                   | 200    | `audit:read`          |
| `listWebhookDeliveries`               | `GET /v1/environments/{environmentId}/webhook-deliveries`             | 200    | `webhooks:read`       |

`startEnvironmentExecution` body is one of:

| Title in the schema | Required fields                                                        |
| ------------------- | ---------------------------------------------------------------------- |
| Start of a Workflow | `workflowId`, `externalSubjectId`, `input`. Optional `conversationId`. |
| Start of an Agent   | `agentId`, `externalSubjectId`, `input`.                               |

The success body is a public Execution. A Workflow run has `workflowId`. An Agent run has `workflowId: null` and `agentId`.

`events:read` is declared on the Environment key scope enum. No registered operation requires it.

`startEndUserExecution` body is `workflowId`, optional `conversationId`, and `input`.
