Linea is a runtime and control plane for production agents. Its SDKs and protocol are open source under Apache 2.0.

These pages are for developers integrating with the open SDKs and the public `/v1` protocol. The hosted workspace is at [platform.getlinea.app](https://platform.getlinea.app). The SDKs are not on npm yet, and the API they call is not a released public surface. Check the protocol in [linea-org/linea](https://github.com/linea-org/linea) when a page and the code disagree.
