Architecture Decision Records preserve why a hard-to-reverse choice was made,
which alternatives were rejected, and what consequences follow. Linea keeps the
records with the platform code they govern. This page summarizes them.

## Decision themes

| Theme            | Examples                                                                               |
| ---------------- | -------------------------------------------------------------------------------------- |
| Product boundary | Agentic behavior analysis supports the platform rather than defining its initial wedge |
| Identity         | Applications, External Subjects, and End-User Sessions are distinct boundaries         |
| Authorization    | Application and Workspace Keys remain non-interchangeable                              |
| Human control    | Approval Requests and Decisions are separate durable resources                         |
| Side effects     | Consent is enforced at the connector gateway and binds an intent digest                |
| Compatibility    | Only the public developer interface is versioned                                       |
| Delivery         | PostgreSQL outbox state is authoritative for asynchronous delivery                     |
| Contracts        | Public wire schemas belong to a browser-safe shared protocol module                    |
